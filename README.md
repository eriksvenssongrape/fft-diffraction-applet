# Fourier Transform & Reciprocal Lattice Explorer

Interactive educational tool for visualizing how real-space crystal structures
(relaxed geometry, atom positions, and lattice vectors)
determine reciprocal-space diffraction patterns through a 2D Fourier transform.

## Features

- Adjustable `a`, `b`, and `γ` lattice parameters. 
- Fractional atom sliders  
- Real-space and reciprocal-space plots (FFT-based)  
- True geometric deformation under lattice changes
